## Projects

### 🎨 AI Image Generation Agent

A powerful Python-based AI agent for generating images from text prompts. Supports multiple AI backends including Hugging Face Diffusers (Stable Diffusion), OpenAI DALL-E, and Stability AI.

**Quick Start:**
```bash
# Install dependencies
pip install -r requirements.txt

# Generate an image
python image_generation_agent.py "a beautiful sunset over mountains"
```

**Features:**
- Multiple AI backends (Hugging Face, OpenAI, Stability AI)
- Easy CLI interface
- Batch generation
- Reproducible results with seeds
- Customizable parameters

**Documentation:** See [IMAGE_AGENT_README.md](IMAGE_AGENT_README.md) for detailed usage instructions.

**Files:**
- `image_generation_agent.py` - Main agent with CLI
- `config.py` - Configuration management
- `example_usage.py` - Usage examples
- `requirements.txt` - Python dependencies
